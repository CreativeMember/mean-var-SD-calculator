# Mean Variance Standard Deviation Calculator
This project is a Python and NumPy-based statistical calculator created as part of the freeCodeCamp Data Analysis with Python certification.
## Features
The program calculates:
- Mean
- Variance
- Standard Deviation
- Maximum value
- Minimum value
- Sum

for:
- Rows
- Columns
- Flattened matrix

## Technologies Used

- Python
- NumPy

## Example

Input:
calculate([0,1,2,3,4,5,6,7,8])

output:
{
  'mean': [[3.0, 4.0, 5.0], [1.0, 4.0, 7.0], 4.0],
  'variance': [[6.0, 6.0, 6.0], [0.67, 0.67, 0.67], 6.67],
  'standard deviation': [[2.45, 2.45, 2.45], [0.82, 0.82, 0.82], 2.58],
  'max': [[6, 7, 8], [2, 5, 8], 8],
  'min': [[0, 1, 2], [0, 3, 6], 0],
  'sum': [[9, 12, 15], [3, 12, 21], 36]
}
